发布日志
发布日志
本文记录 Kimi Work 的版本更新内容，包括新增功能、变更与修复，并持续更新。最新版本下载：
kimi.com/products/kimi-work
3.2.4（2026-08-31）
变更
优化了网络搜索与本地文件等信源在消息回复中引用显示
优化了消息回复中的字号与行间距
修复
修复了部分深色模式下的体验问题
优化了 Windows 端的进程守护
修复了一些 Bug，优化了一些交互与稳定性
3.2.3（2026-08-28）
新增
插件市场上线「新建插件」入口：可直接在插件市场创建插件
修复
桌面宠物细节打磨：优化窗口行为，语言实时跟随应用切换
修复消息报错后编辑重发的会话状态一致性问题
优化了常驻功能的能耗
修复了一些 Bug，优化了一些交互与稳定性
3.2.2（2026-08-26）
新增
新增桌面宠物：Kimi 以桌面宠物形态陪伴与交互
新增 Slash 快捷指令：输入框支持 compact（压缩上下文）、fork（分叉会话）、goal（目标）指令
运行权限新增「默认」选项，全局支持「默认」、「手动允许」、「全部」三档权限
变更
内置浏览器的 Agent 控制改为默认开启
「对话区」聊天的根目录不再共享，每个对话将单独新建一个工作目录
修复
修复首条消息发送时闪现空态的问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.1（2026-08-21）
新增
新增全局唤起 Launcher：支持通过全局快捷键随时随地唤起桌面悬浮胶囊输入框
唤起时自动带入 Finder / 文件资源管理器中当前选中的文件，支持粘贴图片、添加附件与拖拽截屏
输入「/」可呼出插件与技能菜单（支持拼音搜索），并可选择工作区
按住快捷键即可语音输入，提交后收起为迷你胶囊，可一键跳回主应用查看回答
新增消息队列：Agent 回答期间可继续发送消息，新消息自动排队，支持拖拽重排、编辑、删除与详情预览
Work 输入框支持语音听写：点击麦克风或按住快捷键即可开始听写，支持中英混合识别
变更
消息通知逻辑更新：可在设置里切换消息通知规则
修复
优化待机能耗，减少应用空闲时的后台资源占用
修复了 macOS 端 Dock 图标消失的问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.0（2026-08-19）
新增
新增 Agent 内置浏览器：浏览器标签页绑定会话并归入预览区，Agent 可直接操控浏览器完成点击、输入等操作，mac端还支持从本机 Chrome 导入 Cookie 复用已有登录态（默认关闭，可在设置中开启）
16 语言本地化：客户端语言从中英双语扩展到 16 种语言
变更
Kimi WebBridge 插件化：真实浏览器控制改为插件形态，默认关闭、可在设置中开启
看板区的列表页取消，更新为通过顶部tab栏切换
预览区更新看板类型，可在对话预览区打开看板，支持多看板并行打开
修复
消息流式渲染升级：长回复输出更平滑
修复了一些 Bug，优化了一些交互与稳定性
3.1.10（2026-08-16）
修复
修复了 Windows 端部分用户的升级闪退问题
3.1.9（2026-08-15）
新增
个人插件市场上线：插件市场新增「个人插件」板块，可浏览、安装个人开发者插件
修复
修复流式 Markdown 内容偶发不刷新等问题
修复了一些 Bug，优化了一些交互与稳定性
3.1.8（2026-08-11）
新增
消息记录导航：长会话右侧新增消息导航栏，可快速回切到过往消息
会话分支：可从任意回合开出新分支继续探索，继承原会话聊天记录
消息编辑重发：支持修改上一条提问后重新生成
项目文件夹：会话可移入 / 移出项目，项目可置顶到侧栏固定区
文件编辑透明化：Agent 修改文件后生成 diff 摘要卡片，可逐行查看变更并一键回滚；工作区文件随磁盘变化自动刷新
技能发现与创建：Work 内可发现并创建自定义技能，支持技能搜索
固定至桌面的看板组件新增置顶开关
变更
新建独立会话窗口支持Chat功能
输入框内，超长用户消息添加了折叠功能
修复
修复 Windows 端 PDF 文件链接预览问题；深色模式下打开 Work 设置不再闪白；Word 剪贴板粘贴还原为文本而非图片附件
修复了一些 Bug，优化了一些交互与稳定性
3.1.7（2026-08-05）
新增
支持消息级用户反馈：可对助手回复中的具体消息点赞或点踩
变更
固定至桌面的看板组件取消强制置顶
修复
修复了一些 Bug，优化了一些交互
3.1.6（2026-07-29）
新增
PPT 幻灯片编辑器上线：直接在工作台内打开编辑，改完即所得
支持预览区文件与浏览器的截图批注，完成后可直接发给 Agent 修改
支持 Windows 端存储盘迁移：Work 数据可迁移到其他磁盘
Windows 端安装支持自选安装位置
变更
优化了部分 token efficiency 问题
修复
修复了一些 Bug，优化了一些交互
