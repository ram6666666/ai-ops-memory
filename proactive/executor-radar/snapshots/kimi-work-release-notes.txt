本文记录 Kimi Work 的版本更新内容，包括新增功能、变更与修复，并持续更新。最新版本下载：
kimi.com/products/kimi-work
3.2.11（2026-09-18）
变更
详情面板支持展示子 Agent 运行过程
修复
修复 Windows 应用内更新后开始菜单快捷方式悬空的问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.10（2026-09-16）
修复
紧急下线 Windows 分享目标伴生包，修复启动即闪退的问题；分享能力已于 3.2.11 修复后回归
内置技能展示名与描述按界面语言本地化：「/」菜单按本地化名过滤，未交付语种回落英文
文件夹附件卡片点击即在工作台文件树定位对应目录
修复了一些 Bug，优化了一些交互与稳定性
3.2.9（2026-09-14）
新增
部分格式文件新增分享与打开功能：
分享给 Kimi：支持在微信等 App 的分享菜单中直接把文件 / 内容发给 Kimi
用 Kimi 打开：部分文件的右键菜单支持选择用 Kimi 打开
桌面宠物升级：UI 全新升级，支持在会话气泡中快捷回复，不进主窗口也能续聊
预览器更新 PDF 索引区，新增目录与页码跳转
电源模式增加“熄屏后保持唤醒”：屏幕可熄灭，系统保持运行，远控与后台任务不中断
变更
上传或在输入框「@」的文件链接可点击直接在右侧工作台打开预览
图片预览新增复制 / 保存操作
修复
修复队列编辑恢复、浏览器崩溃后导航解锁等多处竞态问题
修复应用功能深色模式配色问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.8（2026-09-12）
变更
防休眠设置改为三档可选：熄屏保持运行、屏幕常亮、关闭
修复
修复设置窗口恢复后白屏的问题
优化长截图缩略图，减少预览内存占用
修复登录刷新竞态，避免旧请求误清登录状态或覆盖新凭证
修复了一些 Bug，优化了一些交互与稳定性
3.2.7（2026-09-11）
新增
截图能力大升级：Launcher 截图支持滚动长截图；截图编辑内一键 OCR 提取图中文字；截图可固定为置顶小窗钉在桌面
会话设定注入：Work 新会话自动携带你的会话设定
支持将文件拖拽到窗口任意位置添加附件，支持文件夹拖拽
新增网站部署插件，安装后本地网站项目可一步云部署
变更
Windows 开机自启改为仅驻留托盘，不再弹出主窗体
Markdown 表格全新设计，超宽表格可横向滚动
提醒中心支持一键全部已读
远程控制消息分段展示，子 Agent 卡与产物卡对齐桌面形态
修复
无麦克风设备自动禁用语音输入，拔麦即停
修复插件上传功能丢失问题
邮件 / 电话外链无法打开时明确告知，不再静默失败
修复额度耗尽时定时任务页卡死的问题
桌面宠物性能与拖拽修复
修复了一些 Bug，优化了一些交互与稳定性
3.2.6（2026-09-07）
新增
新增流内推荐/安装插件功能，自动为用户推荐适合任务的插件并提醒安装
支持通过 GitHub 链接安装插件，方便三方插件引入
变更
插件详情页新增 MCP 连接状态展示与连接管理
退出应用前将确认仍在运行的定时任务
修复
修复了进入设置页某些特定页面后点击“返回”无响应的问题
修复 macOS 覆盖安装被误拦截、Windows 端 CAD 文件误用记事本打开的问题
修复暗色模式部分页面配色、Launcher 消息重复、DOCX 预览宽度适配等问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.5（2026-09-04）
新增
新增远程控制功能：可通过手机远程控制桌面端 Kimi Work
新增应用（Apps）功能，提升 Agent 网页操作的能力与效果可见性
新增对话内搜索功能，支持在对话内快速查找记录
变更
插件/技能市场更新，优化了展现逻辑，支持插件/技能搜索
设置中心改版，兼容打通 Chat 与 Work 模式
修复
修复部分用户登录状态显示异常问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.4（2026-08-31）
变更
优化了网络搜索与本地文件等信源在消息回复中引用显示
优化了消息回复中的字号与行间距
修复
修复了部分深色模式下的体验问题
优化了 Windows 端的进程守护
修复了一些 Bug，优化了一些交互与稳定性
3.2.3（2026-08-28）
新增
插件市场上线「新建插件」入口：可直接在插件市场创建插件
修复
桌面宠物细节打磨：优化窗口行为，语言实时跟随应用切换
修复消息报错后编辑重发的会话状态一致性问题
优化了常驻功能的能耗
修复了一些 Bug，优化了一些交互与稳定性
3.2.2（2026-08-26）
新增
新增桌面宠物：Kimi 以桌面宠物形态陪伴与交互
新增 Slash 快捷指令：输入框支持 compact（压缩上下文）、fork（分叉会话）、goal（目标）指令
运行权限新增「默认」选项，全局支持「默认」、「手动允许」、「全部」三档权限
变更
内置浏览器的 Agent 控制改为默认开启
「对话区」聊天的根目录不再共享，每个对话将单独新建一个工作目录
修复
修复首条消息发送时闪现空态的问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.1（2026-08-21）
新增
新增全局唤起 Launcher：支持通过全局快捷键随时随地唤起桌面悬浮胶囊输入框
唤起时自动带入 Finder / 文件资源管理器中当前选中的文件，支持粘贴图片、添加附件与拖拽截屏
输入「/」可呼出插件与技能菜单（支持拼音搜索），并可选择工作区
按住快捷键即可语音输入，提交后收起为迷你胶囊，可一键跳回主应用查看回答
新增消息队列：Agent 回答期间可继续发送消息，新消息自动排队，支持拖拽重排、编辑、删除与详情预览
Work 输入框支持语音听写：点击麦克风或按住快捷键即可开始听写，支持中英混合识别
变更
消息通知逻辑更新：可在设置里切换消息通知规则
修复
优化待机能耗，减少应用空闲时的后台资源占用
修复了 macOS 端 Dock 图标消失的问题
修复了一些 Bug，优化了一些交互与稳定性
3.2.0（2026-08-19）
新增
新增 Agent 内置浏览器：浏览器标签页绑定会话并归入预览区，Agent 可直接操控浏览器完成点击、输入等操作，mac端还支持从本机 Chrome 导入 Cookie 复用已有登录态（默认关闭，可在设置中开启）
16 语言本地化：客户端语言从中英双语扩展到 16 种语言
变更
Kimi WebBridge 插件化：真实浏览器控制改为插件形态，默认关闭、可在设置中开启
看板区的列表页取消，更新为通过顶部tab栏切换
预览区更新看板类型，可在对话预览区打开看板，支持多看板并行打开
修复
消息流式渲染升级：长回复输出更平滑
修复了一些 Bug，优化了一些交互与稳定性
3.1.10（2026-08-16）
修复

3.1.9（2026-08-15）
新增
个人插件市场上线：插件市场新增「个人插件」板块，可浏览、安装个人开发者插件
修复
修复流式 Markdown 内容偶发不刷新等问题
修复了一些 Bug，优化了一些交互与稳定性
3.1.8（2026-08-11）
新增
消息记录导航：长会话右侧新增消息导航栏，可快速回切到过往消息
会话分支：可从任意回合开出新分支继续探索，继承原会话聊天记录
消息编辑重发：支持修改上一条提问后重新生成
项目文件夹：会话可移入 / 移出项目，项目可置顶到侧栏固定区
文件编辑透明化：Agent 修改文件后生成 diff 摘要卡片，可逐行查看变更并一键回滚；工作区文件随磁盘变化自动刷新
技能发现与创建：Work 内可发现并创建自定义技能，支持技能搜索
固定至桌面的看板组件新增置顶开关
变更
新建独立会话窗口支持Chat功能
输入框内，超长用户消息添加了折叠功能
修复
修复 Windows 端 PDF 文件链接预览问题；深色模式下打开 Work 设置不再闪白；Word 剪贴板粘贴还原为文本而非图片附件
修复了一些 Bug，优化了一些交互与稳定性

支持消息级用户反馈：可对助手回复中的具体消息点赞或点踩
变更

修复
修复了一些 Bug，优化了一些交互
