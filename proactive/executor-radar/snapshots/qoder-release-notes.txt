November 13, 2026
Qoder 0.5.11
Beyond Responses, Proactive Suggestions
Features
Next-step suggestions
: Qoder can proactively suggest what to do next when the composer is idle and empty. Press Tab or Right Arrow to insert a suggestion into your draft, then review and send it.
Custom UI plugins
: Use the plugin-creator skill to build plugins with custom interfaces. Once installed, they can stay open as apps in Qoder, bringing your own tools into your everyday workflow.
Issue collaboration
: Add comments, replies, and attachments, assign issues to available agents, link discussions, and review execution records and results. Available to accounts with project collaboration enabled.
Data import
: Adds Kiro IDE imports for tasks, memory, and supported Skills, MCP configurations, and Powers, with incremental updates. Also improves QoderWork source detection and preservation of workspace information for Codex sessions spanning multiple directories.
Improvements
IM plugin management
: Review connection states, notifications, and pairing requests from enabled IM plugins in one place, with clearer setup guidance and authorization when switching the device handling a connection.
Cloud automations
: Select existing cloud resources and upload supported attachments to provide the capabilities and inputs your automations need.
Browser and webpage context
: Reference tabs from connected, supported browsers with @, and request summaries of public webpage links.
Device connections
: When the target device supports and authorizes it, create a workspace on that device or start a task without a workspace.
Knowledge management
: Improves incremental updates, progress displays, and retries after failures for Repo Wiki and Knowledge Cards. Available team knowledge can be retrieved automatically where account and organization policies allow.
Tasks and attention
: Review and clear eligible local My Attention history. Output files in the task monitor are ordered by their last-modified time, making recent results easier to find.
Network proxy
: Adds SOCKS5 support for manual proxy configuration, with improved credential editing and feedback when applying saved settings.
Qoder Helper
: Improves official-documentation lookup, guidance on where to find features, and configuration explanations, helping you find the information and actions you need.
Remote work
: SSH sessions can send files from your local machine and reference content on the same remote host. The first connection opens the remote home directory by default, and reconnecting keeps the selected directory.
Fixes
Fixed annotations on empty Word table cells failing to send, false connection or permission errors while the editor loads, and tab icon and pagination display issues.
Fixed excessive memory use when converting Excel formulas to values in bulk, and increased the object limit for creating dense presentation slides.
Fixed Sites preview recovery after its entry file is renamed or backed up, navigation from a conversation to a valid annotation, and template-list and design-style picker display issues.
Fixed Windows attachment paths, legacy Skill labels, and large-record reads in QoderWork imports. For sources that support re-importing, individual unavailable images no longer block the remaining content.
Fixed Chrome’s “Send this page” requiring a prior visit to Settings, while preserving the existing draft. Also fixed character-encoding issues in some webpage link previews.
Fixed being unable to re-enter an SSH password after entering it incorrectly, the SSH configuration dialog failing to close on Linux, and WSL incorrectly reporting lost history after switching tasks.

Everyday Polish
Improvements

November 5, 2026
Qoder 0.5.5
Take Documents and Sites Further
Features
Word plugin
: Adds a Word plugin for opening, editing, and saving DOCX files in Qoder, with conversation-based assistance for working on document content.
Sites design canvas
: Adjust Site page content and layout on a design canvas and use annotations to request changes. Add website templates as task attachments and choose a design style while keeping your own instructions.
Local browser access for remote tasks
: Supported remote sessions can use an authorized connection to operate the controlling device’s Qoder built-in browser alongside remote execution.
HarmonyOS tap-to-share
: On supported HarmonyOS devices, transfer images and PDFs from a phone into the current local task or a new task draft, or send local files to the phone with tap-to-share.
Enterprise approval controls
: Enterprise policies can restrict Full Access and Auto approval. When a mode is disabled, subsequent operations follow an available approval mode.
Improvements
Agent Teams
: Select members from the current device, the cloud, and other devices on the same account, enabling collaboration when required. Connected-device workspaces can use their associated teams. Leaders on other devices can participate in discussions; local tasks remain subject to the execution restrictions of the leader’s device.
Plugin creation
: Adds the built-in Plugin Creator to improve conversational plugin creation, customization, and packaging, combining Skills, commands, Agents, Hooks, MCP, and related capabilities.
Local extension installation
: Install plugins and Skills by dragging or pasting files. Plugins requesting Qoder SDK access show a manual authorization prompt during installation or permission changes.
Plan and Goal
: After reviewing a plan, choose Goal execution in supported tasks to continue working toward an explicit outcome.
SSH and WSL
: Improves connection management and workspace creation, including direct SSH host entry, authentication selection, and connection reassociation. Manually disconnecting pauses automatic reconnection while preserving workspaces and task records.
Device connections
: Sets initial pairing permissions according to the account relationship and improves address validation and local-network diagnostics. Explicitly confirm before stopping remote work for an update, and reference cached conversations from offline devices in local tasks.
Model selection
: New tasks can default to an available free official model when the account is confirmed to have exhausted its credits. Adds large-context usage hints, exclusive-pack balance notices, and clearer rate-limit messages.
Diagnostics and feedback
: Improves Qoder Helper’s Hook timing diagnostics and troubleshooting for remote devices.
Cross-device automations
: Use the slash menu in a connected-device conversation to create automations that run and are managed on that device. This entry is not available in SSH or WSL conversations.
Fixes
Fixed stalled backward navigation, missing chapter entries, and conflicts between search navigation and returning to the bottom in long conversations.
Fixed derived tasks losing custom groups, some forked tasks remaining unusable after initialization failures, and missing history links for background subagents.
Fixed restoring one task in an archived workspace also restoring other archived tasks.
Fixed failures when sending structured or Sites template attachments to remote tasks, or withdrawing and resending queued attachments. Also fixed remote Office attachment previews, saving, and generated-file access.
Fixed inconsistent model catalogs, default models, and enterprise model categories in cross-device conversations.
Fixed remote recent-conversation ordering, synchronization recovery after catalog subscriptions end, and live voice state display.
Fixed initial handoff to remote teams, references in follow-up delegation, collaboration activation for plugin Agents, and team history display after account switches.

October 30, 2026
Qoder 0.5.1
Different devices,One flow
Features
Device connections
: Use a pairing code to connect to other Qoder devices on your local network. Access authorized workspaces to run tasks, use terminals, browse the web, and work with files on the connected device. Control workspace access and session synchronization, and revoke connection access when needed.
Cross-device collaboration
: Use @ in a local task to reference a connected device's workspace and delegate tasks. View Agents on other devices, cached conversation history, and device update status. Remote models and browser sessions are managed per execution device.
Needs Me
: Review items that need a response, results that need your attention, and activity from tasks and available collaboration features in one inbox. Filter and search items, handle approvals, and review your history.
Codex data import
: Detect and selectively import Codex conversations, compatible local automations, memory, and supported Skill, MCP, and plugin configurations. Imported plugins start disabled; application-specific capabilities are excluded.
Cloud Agent management
: Create, edit, and manage cloud Agents, configure their models, instructions, and resources, and manage Skills, MCP connections, and memory that can be synced to the cloud. Availability depends on account permissions and cloud service configuration.
Excel plugin
: Added an Excel plugin to create, edit, and analyze spreadsheets through conversation, organize data, calculate formulas, and adjust formatting. Preview, manually edit, and save spreadsheets directly in Qoder.
Improvements
Projects and discussions
: Projects can now be associated with multiple repositories. Search organization members in discussions, with direct additions governed by each member's preferences. Improved mentions, message reactions, and key-message actions.
Agent Teams
: Added a software development expert team template. Create a team of specialized research, development, testing, and review Agents with one click to collaborate on development tasks.
Conversation input
: Improved slash-menu categories and recent items, @ file search, input-history reuse, and attachment previews before sending, along with long-text editing and input responsiveness.
Remote Control
: Added synchronization for task archiving and restoration, improved the display of plan approval details, and increased the transfer limit for individual artifact files to 100 MiB.
Worktrees
: Preserve required project configuration when creating worktrees. When carrying over local changes, keep them unstaged where possible for continued review.
Qoder Helper and feedback
: Qoder Helper can inspect relevant log excerpts when explicitly requested and provides clearer guidance for settings changes. Feedback can also be submitted from the recovery screen after a startup failure.
HarmonyOS foldables
: Added upper-and-lower workspace panels for supported foldables in a partially folded horizontal posture, with layout restoration when unfolding and folding again.
Fixes
Fixed false duplicate-install errors for enterprise-managed plugins and inconsistent discovery and invocation names for commands in subdirectories.
Fixed some settings and MCP management actions failing to follow the current conversation's approval policy.
Fixed capability loading failures when using the slash menu on the home screen with some older General workspaces.
Fixed Git status reads failing or consuming resources for extended periods on Windows, and improved error messages for large repositories.
Fixed default MCP discovery and generated-file access for some SSH connections, along with Windows connection initialization issues.
Fixed Remote Control history ordering, approval-state recovery, and queued-message handling after stopping a task.
Fixed an issue where Qoder stopped waiting too soon when sign-in through an external browser took longer.

August 27, 2026
Qoder 0.1.0
Hello, World!
The All-New Qoder Is Here. Qoder is an agentic coding platform for everyone. You bring the idea, and Qoder gets it done
Since Qoder IDE launched in August 2025, Qoder has grown to 6M+ users worldwide and 100K+ businesses.
Coding is becoming a universal capability. As work shifts from codebases to agent tasks—and from hands-on production to delegation and review—people need a task-centric workspace that lives on their machine. The all-new Qoder is our answer.
What's New
Frontier models, smart routing
: Qoder brings together leading models without locking you into a single one. Choose the model that fits your task, or let the Auto routing engine automatically balance quality, speed, and cost.
Harness for complex tasks
: Qoder’s Harness keeps planning, execution, verification, and self-correction in a continuous loop. For long-running and complex tasks, it retains context, adapts based on real results, and retries or rolls back when needed—all while permission tiers and tool allowlists keep sensitive actions within clear boundaries.
Works in real environments
: With Browser Use and Computer Use, Qoder can operate websites and desktop apps just as you would, so it can get work done in real environments.
An ecosystem that connects
: With 70+ plugins, 20,000+ skills, and 40+ connectors, Qoder connects to the systems where work actually happens: code repositories, documents and data sources, collaboration tools, databases, internal APIs, ticketing systems, and monitoring tools.
Act
Proactive
: Qoder does more than respond to instructions. It proactively brings unresolved errors, changes without tests, and inconsistent logic to your attention—along with task updates and suggested next steps.
This is just the beginning.
Our direction is clear: fewer handoffs, more trustworthy results.
As Coding becomes a universal capability, a coding agent gives anyone the power to turn ideas into reality.
