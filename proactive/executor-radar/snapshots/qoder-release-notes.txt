September 24, 2026
Qoder 0.4.2
Everyday Polish
Improvements
Restored the display of user nicknames in the account area.
Bug Fixes
Fixed an issue where Prompt Suggestion processing could block the next request; suggestion generation no longer delays subsequent chat responses.
Fixed an issue where Side Chat lost the main conversation's context; side chats now correctly carry over the main session's content.
Fixed an issue where deleted sessions in Remote Control were not synced correctly; session state now stays consistent across devices.
Fixed an issue where a shared resource pack disappeared from the usage page after being exhausted; its depleted status is now shown properly.
​
September 23, 2026
Qoder 0.4.1
A New Space for Human and Agent Collaboration
Features
Projects and discussions (Enterprise&Teams)
: Discuss plans, push tasks forward, and bring ideas to life with your Agent, all in one place.
Agent Teams (Enterprise&Teams)
: Create and configure Agents, then bring them together into teams. A team lead delegates work, coordinates members, and summarizes progress.
Cloud automations
: Create scheduled tasks through conversation or manual configuration, then view run history and ask follow-up questions from the desktop app.
Skill evolution suggestions
: After a conversation finishes, Qoder can suggest creating or updating Skills based on reusable experience. Accept a suggestion to open a separate conversation, then confirm the plan before any changes are made. Manage this feature in Settings → General.
Improvements
Workspace indexing
: Choose whether to build an index when creating a local workspace, with access to information about how index data is handled.
MCP configuration
: Added a custom timeout setting so you can adjust the wait time for each service. Configure it in Settings → Extension Management → Connector Management.
Network proxy
: Added support for HTTP/HTTPS proxy URLs containing a username and password, making it easier to connect to proxies that require authentication.
Fixes
Fixed an issue where switching to full access during a running task could cause the operation to stall.
Fixed an issue where selected plugins could be incorrectly marked as unavailable or disappear from the menu after the plugin list refreshed.
Fixed issues with some Chinese text in PDF previews and page edges becoming inaccessible when zoomed in.
Fixed an issue where files with Git Bash-style paths could not be opened on Windows.
​
September 20, 2026
Qoder 0.3.4
Everyday Polish
Fixes
Fixed security-related issues.
​
September 18, 2026
Qoder 0.3.3
Sites: Build and Publish Websites through Conversation
Features
Sites
: Choose a template and build a website through conversation. Preview, publish, and manage your sites directly in the desktop app.
Presentation creation and editing
: Open PPTX files from your workspace to edit and save them directly in the desktop app. Download the Presentations plugin from the marketplace for an enhanced experience.
Computer Use
: Upgraded to Computer Use 2.0 for a smoother experience, now with Linux support. Enable it in Settings-Computer Use to try it out.
Achievement stickers
: Discover and collect 7 new achievement stickers that unlock as you use Qoder.
Response annotations
: Enable this feature in Settings-Experimental Features to select text in an Agent response, add it to the chat input box with an optional comment, and reference the annotation in subsequent replies.
Improvements
Voice input
: Press and hold the mouse button in the chat input box to dictate. Release to leave the transcribed text in the input box for editing before sending.
Send shortcut
: Choose Enter or Cmd/Ctrl+Enter to send messages in settings.
Remote Control
: Automatically sync local conversation history updated within the last 7 days, with improved incremental syncing to reduce duplicate transfers.
Worktree
: Improved starting-point list loading and creation preparation for large repositories, reducing loading or creation failures when there are many local changes.
Fixes
Fixed issues where Remote Control failed to reconnect after an upgrade and older messages could be executed again after reconnecting.
Fixed an issue where the first reply in Side Chat failed to correctly inherit context from the source conversation.
Fixed an issue where replies could fail to appear when messages were sent during conversation compaction.
​
September 12, 2026
Qoder 0.2.5
Everyday Polish
Improvements
File openin: Choose whether to open each file type in the desktop app or its associated system application. Qoder remembers your choice after the file opens successfully.
Real-time voice: Improved connection stability, reducing the likelihood of unexpected disconnections.
File review: Reduced CPU usage when multiple code diffs are expanded alongside an open terminal.
Creative achievements: Your profile now includes Credits and activity stats, along with achievement stickers for 7-, 30-, and 100-day creative streaks.
Fixes
Fixed website sign-in sessions not being shared across tasks in the built-in browser.
Fixed streaming replies failing to automatically scroll to the latest content, and replies getting stuck on older content after layout changes.
Fixed Chinese text input issues in Computer Use.

September 10, 2026
Qoder 0.2.3
Everyday Polish
Improvements
Before performing visual actions such as clicks, Computer Use now verifies that the screenshot is up to date and the target window remains unchanged, improving operation accuracy.
Improved cancellation and timeout handling in Computer Use, making long-running operations more responsive.
Fixes
Fixed an issue where Computer Use might repeat the same action when its result could not be confirmed immediately.

September 9, 2026
Qoder 0.2.2
Network Proxy Support Added
Features
Network proxy
: Added network proxy configuration, with connection testing. Changes take effect after a restart.
Improvements
Model selection
: New sessions now reuse the model you last selected manually, based on your account and runtime environment.
Goal mode
: Added a maximum turn limit for Goal, and Goal timing is now paused when a session is stopped.
Data import
: Improved page grouping, retention of selected items, and task recovery logic.
Fixes
Improved automatic recovery from remote control errors, and fixed Managed SSH session failures in a VPC, BYOK model recognition on mobile, and cross-device sync issues.
Fixed session issues including the inability to stop during task preparation, the model being overridden when interjecting, and cold sessions relying on a stale connection when switching models.
Fixed startup failures on Windows that triggered automatic compatibility mode, corrupted rendering of small icons on macOS, and scrolling in the automation model list.
​
September 8, 2026
Qoder 0.2.1
Mobile remote control is supported
Features
Mobile Remote Control
: Once enabled, you can use your phone to create and run tasks on your computer. The phone and the computer share the same session, and renaming, deletion, task forking, and follow-up questions all sync in both directions.
Session references via drag-and-drop
: Drag a session into the chat input box to reference it.
Improvements
Multitasking performance
: Lower memory usage and reduced messaging overhead when multiple tasks run concurrently.
Visuals
: Updated the empty-state illustration for workspace files.
Conversation output
: No longer collapsed by default; any setting you enabled manually is preserved.
Fixes
Fixed an issue where a failed registration of a historical session prevented the conversation from continuing.
Fixed an issue where the last message briefly disappeared when reverting and resending.
Fixed continuous flickering during session output.
Fixed rendering issues with symbols and formulas in Markdown.

Extension Market
: Smoother category switching and detail layout

Fixed MCP OAuth negotiation failure diagnostics
Fixed Worktree init failure with no retry option
Fixed voice input floating window position not preserved

August 27, 2026
Qoder 0.1.0
Hello, World!
The All-New Qoder Is Here. Qoder is an agentic coding platform for everyone. You bring the idea, and Qoder gets it done
Since Qoder IDE launched in August 2025, Qoder has grown to 6M+ users worldwide and 100K+ businesses.
Coding is becoming a universal capability. As work shifts from codebases to agent tasks—and from hands-on production to delegation and review—people need a task-centric workspace that lives on their machine. The all-new Qoder is our answer.
What's New
Frontier models, smart routing
: Qoder brings together leading models without locking you into a single one. Choose the model that fits your task, or let the Auto routing engine automatically balance quality, speed, and cost.
Harness for complex tasks
: Qoder’s Harness keeps planning, execution, verification, and self-correction in a continuous loop. For long-running and complex tasks, it retains context, adapts based on real results, and retries or rolls back when needed—all while permission tiers and tool allowlists keep sensitive actions within clear boundaries.
Works in real environments
: With Browser Use and Computer Use, Qoder can operate websites and desktop apps just as you would, so it can get work done in real environments.
An ecosystem that connects
: With 70+ plugins, 20,000+ skills, and 40+ connectors, Qoder connects to the systems where work actually happens: code repositories, documents and data sources, collaboration tools, databases, internal APIs, ticketing systems, and monitoring tools.
Act
Proactive
: Qoder does more than respond to instructions. It proactively brings unresolved errors, changes without tests, and inconsistent logic to your attention—along with task updates and suggested next steps.
This is just the beginning.
Our direction is clear: fewer handoffs, more trustworthy results.
As Coding becomes a universal capability, a coding agent gives anyone the power to turn ideas into reality.
